# 역사가 쑥쑥

한국사 시간 여행 퀴즈 게임 (설치형 웹앱).

- 주소: https://mrkimjy.github.io/ssuk/
- 안드로이드(크롬): 메뉴 ⋮ → 앱 설치 / 홈 화면에 추가
- 아이폰(사파리): 공유 → 홈 화면에 추가
- 한 번 열면 인터넷 없이도 실행돼요. 기록은 이 기기에 저장돼요.
